# Contribuer à Cailloute

Merci de garder les échanges, l’interface et les documents d’utilisation en français. Décrivez d’abord le besoin ou le problème dans une issue. Pour le code, partez de la version publique, proposez une modification ciblée et indiquez les tests effectués.

N’ajoutez aucun secret, compte, donnée personnelle, photo sans autorisation ou contenu sans licence compatible. Les exemples et captures doivent utiliser des données fictives identifiées. Le code original proposé est sous MIT ; les données et ressources gardent leur licence propre. Ne modifiez pas une règle de partage ou de confidentialité sans documenter son effet.

Voir `docs/COMPILER.md` pour les commandes. Les données personnelles ne doivent jamais être effacées pour faciliter une migration. Toute évolution visuelle doit rester lisible en jour et en nuit.
