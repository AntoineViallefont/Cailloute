# Signaler un problème de sécurité

Ne publiez pas de secret, adresse privée, jeton, contenu de compte ou preuve exploitable dans une issue publique.

Utilisez [Signaler une vulnérabilité en privé](https://github.com/AntoineViallefont/Cailloute/security/advisories/new) sur GitHub. Décrivez les versions touchées, les étapes minimales et l’impact, avec des données fictives. N’effectuez pas de test sur les comptes ou données d’autrui.

La bêta est maintenue au mieux des disponibilités de l’éditeur, sans délai de réponse garanti. Les correctifs sont publiés dans les versions GitHub.
